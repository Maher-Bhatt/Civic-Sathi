Sathi Pehchaan — Federated Identity

ONE IDENTITY. ONE LOGIN. MULTIPLE CONNECTED SERVICES.

⚠ Sathi Pehchaan is an OAuth2/OIDC-compatible design concept demonstrated in this prototype. It does NOT integrate with Aadhaar, MeriPehchaan, DigiLocker, or any live government identity system. All identities are synthetic.

One Identity

A citizen authenticates once. Sathi Pehchaan issues a SAT-ID canonical identity that works across all connected systems without requiring separate registrations.

Consent-Gated Sharing

Data from System A is only visible to System B when the citizen has granted explicit, purpose-scoped consent via Sathi Sahamati. Revocation is immediate.

Unified Tracking

One SAT-YYYY-NNNNNN tracking ID links the same grievance across Civic Sathi and the State Grievance Service. The citizen sees one status view instead of two separate portals.
